# Fiche Firefox Add-ons (AMO)

Dépôt sur https://addons.mozilla.org/developers/ (compte Mozilla gratuit). Paquet : `npm run build:blocklist` puis
`npm run package:firefox` → `sortie/rempart-firefox-<version>.zip`. Vérification avant dépôt :
`npx web-ext lint --source-dir <dossier du zip décompressé>` (0 erreur, 0 avertissement attendu).

## Dépôt du paquet

- **Distribution** : « Sur ce site » (*On this site*) : la fiche est publique sur addons.mozilla.org.
- **Plateformes** : Firefox (ordinateur). Firefox pour Android peut rester décoché pour l'instant (non testé).
- **Code source** : « Non » à la question sur les générateurs de code, minificateurs ou outils de compilation.
  Le JavaScript est livré tel quel. Les fichiers `rules/blocklist-*.json` sont des données (listes de domaines),
  pas du code ; la façon de les régénérer est expliquée dans les notes pour l'examinateur.

## Fiche

- **Nom et résumé** : lus dans le paquet (`_locales`), rien à saisir.
- **Catégorie** : Confidentialité et sécurité (*Privacy & Security*).
- **Adresse électronique d'assistance** : laisser vide (ou l'adresse de contact dédiée au projet, jamais une adresse perso).
- **Site d'assistance** : https://github.com/Swedii/Rempart/issues
- **Page d'accueil** : https://github.com/Swedii/Rempart
- **Licence** : GNU General Public License v3.0 (GPL-3.0).
- **Politique de confidentialité** : cocher « Ce module a une politique de confidentialité » et coller le texte de
  `PRIVACY.md` (AMO demande le texte lui-même, pas un lien).
- **Description** : reprendre les descriptions détaillées FR et EN de `store/chrome-web-store.md`
  (fiche française par défaut, ajouter l'anglais).
- **Captures** : `store/captures/fr/1-blocage.png` à `4-reglages.png` (fiche FR), `store/captures/en/…` (fiche EN).

## Notes pour l'examinateur / Notes to reviewer

```
No account, login or configuration is needed: protection is active as soon as the add-on is installed.

1. Blocking: open any well-known adult site (e.g. pornhub.com). The request is redirected to the Rempart block page.
2. SafeSearch: search anything on google.com or bing.com: the results URL is redirected to the SafeSearch version (safe=active / adlt=strict). On youtube.com, Restricted Mode is enforced.
3. Image search: on Google Images, thumbnails are blurred; clicking one reveals it.
4. Settings: open the add-on's options page. Settings can only be made stricter, never looser (by design).
5. Unlock process (optional, slow by design): on the block page, "I still want to access it" starts a 30-minute wait with the tab open, with reflection questions, a text to retype by hand and 5 captchas.
6. False positive: on the block page, "Nothing pornographic on this site?" opens a pre-filled GitHub issue form and lets the user allow the site locally after 24 hours.

Host permission <all_urls>: pornographic content can appear on any site. The content script only checks the standard adult-content meta tags (RTA label, rating=adult) and blurs image search results; it also filters adult-marked posts on reddit.com and x.com. Nothing is collected, stored remotely or transmitted; the add-on makes no network requests of its own (data_collection_permissions: none).

All JavaScript is unminified and hand-written. rules/blocklist-*.json are data files (declarativeNetRequest rules listing about 490,000 domains from the OISD NSFW list, GPL-3.0), generated by tools/build-blocklist.mjs in the public repository: npm install && npm run build:blocklist && npm run package:firefox.
Source code: https://github.com/Swedii/Rempart
```

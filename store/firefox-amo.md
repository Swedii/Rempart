# Fiche Firefox Add-ons (AMO)

Dépôt sur https://addons.mozilla.org/developers/ (compte Mozilla gratuit). Paquet : `npm run build:blocklist` puis
`npm run package:firefox` → `sortie/rempart-firefox-<version>.zip`. Vérification avant dépôt :
`npx web-ext lint --source-dir <dossier du zip décompressé>` (0 erreur, 0 avertissement attendu).

## Notes pour l'examinateur / Notes to reviewer

```
No account, login or configuration is needed: protection is active as soon as the add-on is installed.

1. Blocking: open any well-known adult site (e.g. pornhub.com). The request is redirected to the Rempart block page.
2. SafeSearch: search anything on google.com or bing.com: the results URL is redirected to the SafeSearch version (safe=active / adlt=strict). On youtube.com, Restricted Mode is enforced.
3. Image search: on Google Images, thumbnails are blurred; clicking one reveals it.
4. Settings: open the add-on's options page. Settings can only be made stricter, never looser (by design).
5. Unlock process (optional, slow by design): on the block page, "I still want to access it" starts a 30-minute wait with the tab open, with reflection questions, a text to retype by hand and 5 captchas.
6. False positive: on the block page, "Nothing pornographic on this site?" opens a pre-filled GitHub issue form and lets the user allow the site locally after 24 hours.

Host permission <all_urls>: pornographic content can appear on any site. The content script only checks the standard adult-content meta tags (RTA label, rating=adult) and blurs image search results; it also filters adult-marked posts on reddit.com and x.com. Nothing is collected, stored remotely or transmitted (data_collection_permissions: none). The only request the add-on makes itself is, on reddit.com, Reddit's public /r/<name>/about.json to check whether a community is marked 18+.

All JavaScript is unminified and hand-written. rules/blocklist-*.json are data files (declarativeNetRequest rules listing about 490,000 domains from the OISD NSFW list, GPL-3.0), generated by tools/build-blocklist.mjs in the public repository: npm install && npm run build:blocklist && npm run package:firefox.
Source code: https://github.com/Swedii/Rempart
```

## Politique de confidentialité, texte simple (FR)

```
Rempart ne collecte aucune donnée. Pas de compte, pas de statistiques, pas de publicité, pas de serveur Rempart : rien de ce que vous faites n'est envoyé au développeur ni à qui que ce soit.

Pour fonctionner, l'extension lit et enregistre certaines informations uniquement sur votre appareil :
- l'adresse des pages que vous ouvrez, pour la comparer à la liste de sites bloqués et afficher le site demandé sur la page de blocage (mémoire de l'onglet, effacée à sa fermeture) ;
- les balises « contenu adulte » d'une page (RTA, rating), pour bloquer un site qui se déclare lui-même réservé aux adultes (seul le nom de domaine est retenu, sur l'appareil) ;
- vos réglages, votre compteur de jours, vos déverrouillages et les réponses écrites pendant un déverrouillage (stockage local du navigateur) ;
- les sites que vous autorisez (faux positifs), pour ne plus les bloquer (stockage local du navigateur).
Ces données ne quittent jamais votre appareil. Elles sont supprimées quand vous désinstallez l'extension.

Les seules connexions réseau que Rempart provoque :
- Reddit : sur reddit.com, l'extension demande à Reddit lui-même si une communauté est réservée aux adultes (adresse publique /r/<nom>/about.json), exactement comme le fait le site Reddit que vous êtes en train d'utiliser.
- Signalement d'un faux positif : seulement si vous cliquez sur « Signaler », un onglet GitHub s'ouvre avec le nom de domaine pré-rempli. Rien n'est envoyé tant que vous ne validez pas vous-même le ticket sur GitHub, qui est public.

Questions ou remarques : https://github.com/Swedii/Rempart/issues
```

## Privacy policy, plain text (EN)

```
Rempart collects no data. No account, no analytics, no ads, no Rempart server: nothing you do is sent to the developer or to anyone else.

To work, the extension reads and stores some information only on your device:
- the address of the pages you open, to match the domain against the block list and show the requested site on the block page (tab memory, cleared when the tab closes);
- a page's "adult content" tags (RTA, rating), to block a site that labels itself as adults-only (only the domain name is kept, on the device);
- your settings, streak counter, unlocks and the answers you write during an unlock (browser local storage);
- sites you allow (false positives), to stop blocking them (browser local storage).
This data never leaves your device and is deleted when you uninstall the extension.

The only network connections Rempart causes:
- Reddit: on reddit.com, the extension asks Reddit itself whether a community is adults-only (public /r/<name>/about.json address), just as the Reddit site you are using does.
- False-positive report: only if you click "Report", a GitHub tab opens with the domain name pre-filled. Nothing is sent unless you submit the issue on GitHub yourself, where it is public.

Questions or comments: https://github.com/Swedii/Rempart/issues
```
